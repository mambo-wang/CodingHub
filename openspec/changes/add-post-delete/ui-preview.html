6. 可访问性 (a11y) 检查清单

  • 删除按钮 aria-label="删除帖子"
  • 图标删除按钮 aria-label="删除此帖"
  • ConfirmDialog 使用 role="dialog" + aria-modal="true" + aria-labelledby + aria-describedby
  • 打开对话框时焦点落在"确认删除"按钮（autofocus）
  • 关闭对话框时焦点回到触发按钮（实现时处理）
  • 焦点环可见（outline: 2px solid var(--color-primary)）
  • 颜色对比度：白字 on 红底 #EF4444 = 4.7:1 ≥ AA
  • prefers-reduced-motion: reduce 关闭淡入/缩放动画
  • 错误提示 role="alert" + aria-live="assertive"
  • 键盘可达：Tab 循环、Esc 关闭、Enter 触发
  • 无 emoji，所有图标使用 Lucide SVG（Trash2 / Loader2 / X）
  • 移动端 / 平板 / 桌面三档响应式不溢出
