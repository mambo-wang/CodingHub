## 新增 Skill: openspec-api-test

创建了 `.codebuddy/skills/openspec-api-test/SKILL.md`，仿照 `openspec-browser-test` skill 的结构，但使用 curl 命令做接口自动化测试而非浏览器 UI 测试。

核心流程：
1. 解析 `specs/**/*.md` 中的 `#### Scenario` 块（WHEN/THEN 格式）
2. 从 WHEN 提取 HTTP 方法/路径/角色/请求体，从 THEN 提取预期状态码
3. 准备测试账号（超管 admin/Cloud@1234 + 动态创建 USER/ADMIN 测试账号）
4. 创建者创建测试内容（工具/帖子/微课）获取 ID
5. 角色映射到 token，`{id}` 替换为实际 ID，生成 curl 命令
6. 执行测试对比 HTTP 状态码，输出报告到 `openspec/changes/<change>/api-test-report.md`

与 `openspec-browser-test` 的区别：本 skill 聚焦后端 REST API 接口测试，不依赖 opencli，仅用 curl + python3 解析 JSON。

同时创建了对应的 command `.codebuddy/commands/opsx/api-test.md`，仿照 `browser-test.md` 结构，用法为 `/opsx:api-test [change-name]`。流程：确定 change → 加载 skill → 验证后端运行 → 解析 spec 场景 → 准备测试账号/内容 → 执行 curl 测试 → 失败自动修复 → 清理数据 → 生成报告到 `openspec/changes/<change>/api-test-report.md`。
