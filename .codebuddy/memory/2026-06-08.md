## OpenSpec 新增 impact-analysis artifact

- 在 `ui-design-to-browser-test` schema 中新增 `impact-analysis` artifact（条件必选），位置已调整为 `design` 之后、`tasks` 之前。
- 调整原因：`design.md` 已列出具体文件/类/源码与测试对应关系，更适合作为 codegraph 扫描入口；影响分析可校验 design 是否漏掉调用方/依赖/测试。
- 模板：`openspec/schemas/ui-design-to-browser-test/templates/impact-analysis.md`，包含 8 章节：改动范围、调用图、依赖链、受影响测试、风险评估、层级依赖校验（lint-arch.sh）、回归测试建议、检查清单。
- 实施方式：使用 Task(code-explorer) 子代理扫描调用链，结合 `scripts/lint-arch.sh` 校验层级依赖。
- 触发逻辑：`design.md` 全部源码文件为新增 → 跳过；存在任意现有源码文件 → 必选。
- `tasks` 不硬依赖 `impact-analysis`（避免纯新增场景卡住），改为指令内说明"如已生成则参考其调用图/受影响测试/回归建议/设计修正建议"。
- 当前 schema artifact 依赖链：proposal → specs/design-system → design → impact-analysis；ui-preview 依赖 design-system + design；tasks 依赖 specs + design + design-system + ui-preview，并软参考 impact-analysis。
