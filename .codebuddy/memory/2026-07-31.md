## CodeWiki MCP "Connection closed" 修复

- 现象：MCP error -32000 Connection closed；CLI 启动即 `ModuleNotFoundError: codewiki.src.be.dependency_analyzer.analyzers.route_extractors`。
- 根因：`site-packages/codewiki/` 残留一份旧实体拷贝（历史非 editable 安装遗留），遮蔽了 editable 安装（源码 `/Users/kirito/repos/CodeWiki-CN`），import 走了缺新模块的旧代码。
- 修复：`rm -rf /Users/kirito/miniconda3/lib/python3.13/site-packages/codewiki`，editable 的 `__editable__.codewiki-1.0.1.pth` 自动接管。验证 `codewiki --help` 与 route_extractors 导入均 OK。
- 经验：editable 包报缺模块时，先检查 site-packages 是否有同名实体目录遮蔽（`pip show` 看 Editable project location + `ls site-packages/<pkg>`）。
