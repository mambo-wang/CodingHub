# 2026-06-01 工作日志

## MCP Server 重构完成

### 完成内容
- 创建 MCP Server 核心类 `McpServer.java`，基于 JSON-RPC 2.0 协议
- 创建 MCP HTTP 控制器 `McpController.java`，支持 SSE 端点 `/mcp/sse`
- 创建 STDIO 入口 `McpStdioMain.java`，支持本地 AI Desktop 连接
- 在 `ToolRepository` 添加 MCP 所需查询方法
- 配置 `application.yml` MCP 参数

### MCP 端点
- HTTP/SSE: `GET/POST http://localhost:8080/mcp/sse`
- JSON-RPC: `POST http://localhost:8080/mcp/message`
- 健康检查: `GET http://localhost:8080/mcp/health`

### 工具列表 (4个工具)
1. `searchTools` - 搜索工具列表
2. `getTool` - 获取工具详情
3. `getCategories` - 获取所有分类
4. `getToolStats` - 获取工具统计信息

- 未使用 Spring AI MCP Server Starter（与 Spring Boot 3.2.5 不兼容）
- 采用手动实现 MCP JSON-RPC 2.0 协议
