### 技术栈
- Spring Boot 3.4.4
- Spring AI 1.0.0-M7
- Spring AI MCP Server WebFlux Starter

### 问题
Spring AI MCP Server 自动配置匹配成功但未创建路由，所有请求返回 404。
可能是 Spring AI 1.0.0-M7 与 Spring Boot 3.4.4 的兼容性问题。

### 结论
继续使用主项目中的手写 MCP Server (JSON-RPC 2.0)
