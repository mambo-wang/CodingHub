## 打包部署产物

### 目录结构
```
codinghub/
├── iaihub.jar          # 后端 Spring Boot JAR
├── dist/               # 前端构建产物
├── config/
│   └── application.yaml  # 外置配置文件
├── start.sh            # 启动脚本
└── nginx.conf          # Nginx 配置（监听 17888）
```

### 部署说明
1. 后端：`./start.sh` 读取外置 `config/application.yaml`
2. 前端：由 Nginx 托管，代理 `/api/` 到后端 8080
3. 端口：Nginx 17888，前端通过 Nginx 访问
