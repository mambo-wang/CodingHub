## 关键经验

- 本项目 `test/`、`backend/src/main/resources/static/`、`openspec/changes/user-nickname-feature/` 等目录下大量文件归 `root` 所有，导致 IDE 工具无写权限；任何 `git checkout --`、`git reset --hard`、`git clean` 失败时都需要 `sudo` 兜底。
- 项目改名/分支切换前优先做 `git status` 与 `git log origin/<branch>` 对比，避免本地 HEAD 落后于远程。
- 工作区已干净的判定：`git status --short` 仅显示预期 untracked（如 `.codebuddy/memory/YYYY-MM-DD.md`），且 `git diff --stat` 为空。
