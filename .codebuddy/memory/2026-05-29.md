### 发现并修复的问题

**问题1: 后端懒加载异常 (LazyInitializationException)**
- **原因**: ToolService 中非 @Transactional 方法访问 Tool 实体的懒加载关联（category, uploader）导致 Session 已关闭
- **修复**: 为 getTools, getToolById, getMyTools 方法添加 @Transactional(readOnly = true)

**问题2: 前端 API 代理路径不匹配**
- **原因**: Vite 代理将 `/api` 映射到 `http://localhost:8080`，但前端代码请求 `/api/tools`，而后端实际路径是 `/api/v1/tools`
- **修复**: 修改 vite.config.ts 添加 rewrite 规则，将 `/api` 重写为 `/api/v1`

### 修改的文件
- `backend/src/main/java/com/iaihub/toolbox/service/ToolService.java` - 添加 @Transactional(readOnly = true)
- `frontend/vite.config.ts` - 添加代理路径重写规则

### Bug 修复：文件列表不显示
**问题**：`getToolFiles` 返回 `res.data`（整个 ApiResponse），但实际应该取 `res.data.data`（FileListResponse）

**修复**：修改 `frontend/src/services/api.ts`:
```typescript
getToolFiles: (toolId: number): Promise<FileListResponse> => {
  return api.get(`/tools/${toolId}/files`)
    .then(res => res.data.data as FileListResponse)  // 原来是 res.data
},
```
