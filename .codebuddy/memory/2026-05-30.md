### 收藏功能 Server Error 修复

**问题**：`/forum/my-favorites` 页面报 "Internal server error"

**根因调查**：
1. 检查 network 发现 `GET /api/v1/post-favorites/posts` 返回 500
2. 但旧接口 `GET /api/v1/post-favorites` 正常返回
3. 问题在 `PostFavoriteService.getUserFavoritePosts()` 方法

**修复**：
1. 后端新增 `/api/v1/post-favorites/posts` 接口返回帖子详情
2. `PostFavoriteService` 添加 `getUserFavoritePosts()` 方法
3. 前端 `api.ts` 的 `getMyFavorites` 改为调用 `/post-favorites/posts`
4. 需要重启后端才能加载新代码（编译缓存问题）

**验证**：使用 `opencli_test_user` 登录后，我的收藏页面正常显示帖子"呃呃呃"
