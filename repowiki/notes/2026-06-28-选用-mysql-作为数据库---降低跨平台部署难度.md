## 背景
CodingHub 支持 Windows / macOS / Linux 三平台部署，目标用户包括个人开发者和小型团队，需要选择一种在三个平台上都容易安装和维护的数据库方案。

## 决策
采用 **MySQL 8.x** 作为主数据库。

## 理由
- MySQL 在 Windows、macOS、Linux 上均有官方安装包和 Homebrew / apt / yum 等包管理器支持，安装流程成熟
- 相比 PostgreSQL（Windows 下配置相对复杂）、SQL Server（仅 Windows/macOS 原生友好）、MongoDB（不支持复杂关联查询），MySQL 在跨平台易用性上平衡最好
- 生态完善，Flyway、MyBatis、JPA 等 Java 工具链对 MySQL 的支持最为成熟
- 社区文档丰富，中文资料充足，降低团队和社区贡献者的上手成本

## 备选方案
- **PostgreSQL**：功能更强大，但 Windows 安装配置较 MySQL 复杂，且部分用户不熟悉
- **SQL Server**：跨平台支持有限，社区版功能受限
- **H2 / SQLite**：适合本地开发但不适合生产环境
- **MongoDB**：文档型数据库，与项目结构化数据模型不匹配

## 影响
- 降低部署门槛，新手用户可快速完成环境搭建
- 后端使用 Flyway 管理迁移，数据库版本变更与代码同步
- 连接配置集中管理，支持运行时通过环境变量切换
