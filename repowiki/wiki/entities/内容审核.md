# 内容审核

## Definition
内容治理能力：管理员（ADMIN/SUPER_ADMIN）可删除和编辑任何用户的工具/帖子/微课，统一权限模型 `canModify = isOwner || isAdmin`。建立在 [[用户角色审批]] 的三级角色之上，是平台内容安全的基础防线。

## Key Attributes
- 权限对称：`canEdit === canDelete`；Service 签名由 `Long userId` 改为 `User user`，直接读 `user.getRole()`。
- 删除走 `ConfirmDialog` 二次确认 + 软删除（可恢复）；前端列表卡片 opacity 降级 + hover 高亮。
- 前端抽取 `useContentPermissions` composable；后端仍独立校验（前端被绕过也拦截）。

## Relationships
- 前置条件 [[用户角色审批]]；与 [[软删除状态机]] 配合保证可恢复。
- 影响 [论坛模块](论坛模块.md)、[工具广场](工具广场.md)、[微课视频](微课视频.md) 三域编辑/删除入口。
