# 标签系统

## Definition
跨模块统一标签体系：共享 `tag` 表（带 `tag_type` TOOL/FORUM/VIDEO）+ 各模块独立关联表（`tool_tag`/`video_tag`/`forum_post_tag`）。任何登录用户可创建标签，全局唯一名 + 独立关联表，无层级树/权限。

## Key Attributes
- `tag` 表 `UNIQUE(name, type)` 防并发重复；`TagService.resolveOrCreateTags` 捕获 `DataIntegrityViolationException` 回退。
- 查询侧：`EXISTS` 子查询按 tagId 筛选（如 [[工具按标签筛选设计]]）；前端 `TagBadge` 可点击触发筛选。
- 论坛标签打通现有 ForumTag 后端到前端；MCP `tags` 接受标签名列表自动创建。

## Relationships
- 应用于 [工具广场](工具广场.md)（筛选/卡片）、[微课视频](微课视频.md)（封面/标签）、[论坛模块](论坛模块.md)（标签打通）。
- 自动创建逻辑见 [[工具 UI 与 MCP 修复设计]]。
