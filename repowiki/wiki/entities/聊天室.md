# 聊天室

## Definition
全局公共实时聊天能力（登录用户 + 游客均可收发），与异步 REST 互动在传输模型/数据归属/生命周期上明确区分：独立建模 `chat_message`，不复用 [统一互动](统一互动.md)。WebSocket + STOMP + SimpleBroker（单实例，预留 Redis relay）。

## Key Attributes
- 握手鉴权：`?token=<jwt>` 查询参数，构造 `ChatPrincipal{userId?,displayName,avatarUrl?,ipHash,admin,sessionId}`；无 token 视为游客需填 displayName。
- 频率限制：`ChatService` 内存 2s/条，限流回送错误帧不入库；管理员软删除 `status=DELETED` + 广播 DELETE 事件。
- 在线人数 `ChatPresenceListener` 广播 `{online:N}`；进房加载最近 50 条；status 仅 ACTIVE/DELETED。
- 复用统一互动的 IP 哈希 / XSS / 软删除 / JWT 做法，但不复用其表。
