# 双数据库

## Definition
后端同时兼容 MySQL 与 PostgreSQL 的双库共存能力，通过 Spring Profile 选择其一，业务代码零改动（仅 `User` 反引号注解微调）。Schema 由同一份实体 + `ddl-auto:update` 在两库均有效。

## Key Attributes
- 双驱动共存于 `build.gradle`；`application.yml` 多文档按 `spring.config.activate.on-profile` 切 mysql/postgresql。
- 方言自动探测（Hibernate 6 按 JDBC 元数据）；主键 IDENTITY、枚举 STRING 两库可移植。
- 保留字 `user`：`@Table(name="user")` + `globally_quoted_identifiers=true` 全局引号。
- 同一时刻只连一个库，不引多数据源路由/双写；初始化脚本按库分别提供。

## Relationships
- 概念见 [[双库配置驱动]]；影响全部模块的持久化层（[用户实体](用户实体.md) 的 `user` 表处理最具代表性）。
