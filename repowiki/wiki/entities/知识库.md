# 知识库

## Definition
RAG 知识库模块，提供知识库生命周期管理、文档上传/检索与语义搜索。采用「MySQL 元数据 + RAG 向量存储」混合模式，Java 后端作权限/代理中间层，RAG Python 服务（`:8000`）负责向量与检索。

## Key Attributes
- 元数据表：`knowledge_base` / `kb_document`（status 软删除）；RAG collection 名 = 用户输入名（查重 409）。
- 文档上传：经 [[异步批量上传]] 的批处理 + 状态轮询；直连链路见 [[RAG直连架构]]。
- 分块质量：[[RAG自适应分块]] 的 Protected Patterns / 自适应策略 / 混合检索。
- 搜索返回 chunk 文本片段（含来源/分数），非对话；免登录。

## Relationships
- MCP 暴露见 [[MCP工具集]]（kb_* 工具）；前端 UX 见 [[知识库 UX 改进设计]]。
- 文档 metadata 表 `kb_document` 在 [[RAG直连架构]] 后停止写 MySQL（仅保留兼容）。
