# 微课视频

## Definition
独立视频共享模块（MVP）：参考论坛互动模式构建上传/列表/详情/流式播放与点赞/评论/收藏。本地磁盘存储 + HTTP Range 边下边播，单文件 ≤1GB、仅 MP4、不转码。

## Key Attributes
- 表：`video` / `video_comment` / `video_like` / `video_favorite`；`video.status` NORMAL/DELETED 软删除。
- 播放：`GET /api/videos/{id}/stream` 免登录 Range；封面用前端 Canvas 截帧（见 [[封面/描述/标签设计]]）。
- 互动 API 路径 `/api/videos/...`，后被 [[统一互动架构]] 取代（统一点赞/评论/收藏）。

## Relationships
- 复用论坛式互动思路，与 [论坛模块](论坛模块.md)、[统一互动](统一互动.md) 同源设计。
- 排序置顶见 [[排序与置顶]]（Video 补全 score 字段）。
