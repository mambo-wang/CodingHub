# 用户实体

## Definition
平台核心账户模型 `User`，承载身份认证、展示信息与权限状态。贯穿所有模块，是 JWT、`isOwner` 判定与三级角色审批的基础。

## Key Attributes
- 展示字段：`username`(唯一) / `nickname`(唯一,nullable) / `avatarUrl`(nullable) / `email`。
- 权限字段：`role` ENUM(USER/ADMIN/SUPER_ADMIN) + `status` ENUM(ACTIVE/PENDING/REJECTED/DISABLED)，二者正交。
- 认证：JWT 仅放 userId，filter 每次请求查库读 role/status 使审批即时生效。
- 登录支持用户名或邮箱自动识别；注册密码仅校验长度 ≥6。
