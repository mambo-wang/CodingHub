# 消息通知

## Definition
站内消息中心，由 `NotificationService` 产生并管理用户维度的通知（点赞/评论回复/管理员审批）。前端 30s 轮询拉取，不引入实时推送。

## Key Attributes
- 通知类型：`LIKE` / `COMMENT_REPLY` / `ADMIN_APPROVED` / `ADMIN_REJECTED`（无 FAVORITE/FOLLOW）。
- 单一注入点：在 [统一互动](统一互动.md) 的 `addComment`/`toggleLike` 注入 → 一处覆盖三域；注册审批在 `UserService` 注入。
- 不通知自己（`actorId==ownerId` 跳过），全部 try-catch 包裹为「尽力副作用」。

## Relationships
- 事件源来自 [[统一互动架构]] 的统一服务与 [[用户角色审批]] 的审批流。
- 集成设计见 [[消息中心通知集成设计]]。
