# 统一互动

## Definition
平台横向互动能力的统一实现：将工具/论坛/微课三模块各自重复的 10 张点赞/评论/收藏表合并为 `unified_like` / `unified_comment` / `unified_favorite` 三张通用表，由一套 `Unified*Service` + `UnifiedInteractionController`（`/api/v1/interactions`）服务三域。

## Key Attributes
- 多态目标：`target_type VARCHAR(20) + target_id BIGINT`，枚举 TOOL/FORUM_POST/VIDEO，无数据库级外键。
- 匿名点赞/评论用 `ipHash=SHA256(remoteAddr)`；登录时 user_id 非空、ip_hash 空。
- 嵌套评论 `parent_id`/`root_id`；评论点赞被砍掉（like 只服务内容主体）。
- 主表冗余 `likeCount/commentCount`，Service 同步更新保证性能。

## Relationships
- 架构决策见 [[统一互动架构]]（含「禁止重复造轮子」铁律）。
- 并入前各域自实现：[论坛模块](论坛模块.md)（收藏）、[微课视频](../modules/微课视频.md)（点赞/评论/收藏）。
- 个人中心聚合展示见 [[个人中心我的互动设计]]，事件源供 [[消息通知]] 接线。
