# 论坛模块

## Definition
平台的社区内容域，提供帖子发布、分类、标签、楼中楼评论、点赞与收藏。是 CodingHub 除工具广场外的第二大内容模块，后端 `forum` 子包 + 前端 `forum` 页面/组件，6 张表持久化。

## Key Attributes
- 实体：`ForumCategory` / `ForumTag` / `ForumPost`(status NORMAL/DELETED/HIDDEN) / `ForumPostTag` / `ForumComment`(parent_id+root_id 楼中楼) / `ForumLike`。
- API 前缀 `/api/forum/...`（**无 /v1**，历史遗留，区别于核心 `/api/v1/...`）。
- 匿名评论：IP+SHA256 hash 存 `ipHash`，首次需填昵称。
- 软删除状态机贯穿帖子/评论（见 [[软删除状态机]]）。

## Relationships
- 互动能力早期自实现，后并入 [[统一互动架构]]（收藏/点赞统一）。
- 依赖 [[用户实体]] 的昵称/头像展示，`isOwner||isAdmin` 治理权限见 [[用户角色审批]]。
- 排序置顶见 [[排序与置顶]]，热度见 [[热度评分]]。
