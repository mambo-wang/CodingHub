# 工具广场

## Definition
平台核心内容域，工具的 CRUD、分类、上传、展示与互动。后端 `Tool`/`ToolFile`/`Category` 等实体 + 前端 tool 页面。是 [统一互动](统一互动.md) 之外用户贡献内容的主入口。

## Key Attributes
- 上传约束：≤50MB/≤200MB，防路径穿越、归属校验、覆盖语义；格式白名单默认空（见 [[允许任意工具附件格式设计]]）。
- 展示增强：自定义 logo 三级回退、四项统计（浏览/点赞/收藏/下载，见 [[工具 Logo 与统计设计]]）。
- 筛选：categoryId + keyword + tagId（见 [[工具按标签筛选设计]]）。
- 导航优化：单页 Tab 切换「我的工具/我的收藏/上传」（见 [[工具广场优化设计]]）。

## Relationships
- 互动能力并入 [[统一互动架构]]；标签见 [[标签系统]]；MCP 工具见 [MCP工具集](MCP工具集.md)。
- 热度见 [[热度评分]]，排序置顶见 [[排序与置顶]]。
