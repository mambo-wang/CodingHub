# 留言反馈

## Definition
轻量留言板模块：用户可匿名提交留言（内容必填，昵称/联系方式/分类可选），公开倒序展示；管理员可回复与软删除。单表 `feedback_message`，管理员回复同表字段（不建独立回复表）。

## Key Attributes
- 匿名模式参考 [[统一互动架构]]（有 JWT 关联 userId，无则 ipHash），但不接入 unified-interactions（TargetType 不新增）。
- API 前缀 `/api/v1/feedback`（新模块走 v1，与论坛 `/api/forum` 历史遗留不同）。
- `category` VARCHAR 存枚举（SUGGESTION/BUG_REPORT/PRAISE/OTHER）；`status` 仅 NORMAL/DELETED。

## Relationships
- 匿名思路与 [统一互动](统一互动.md)、[聊天室](聊天室.md) 同源，但各自独立实现。
