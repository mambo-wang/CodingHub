# 软删除状态机

## Definition
平台统一的「不物理删除」数据管理范式：内容实体（Tool/ForumPost/Video/Comment/ChatMessage/FeedbackMessage）用 `status` 枚举标记删除（DELETED/HIDDEN），查询默认过滤，保留可恢复性。

## Key Points
- 状态枚举：NORMAL / DELETED（基础），论坛另含 HIDDEN；聊天室仅 ACTIVE/DELETED。
- 删除入口统一走 `ConfirmDialog` 二次确认（纯前端删除需求强化了该组件）。
- 查询层默认 `status != DELETED` 过滤；聚合统计（likeCount/commentCount）同步更新保持一致性。
- 与 [内容审核](../entities/内容审核.md) 配合：管理员删除是软删除，可恢复（区别于硬删除）。
