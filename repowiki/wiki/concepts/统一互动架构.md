# 统一互动架构

## Definition
平台横向互动能力的核心架构决策：将分散在三模块的点赞/评论/收藏合并为 3 张通用表（unified_like/unified_comment/unified_favorite）+ 一套 Controller/Service，以 `target_type+target_id` 多态服务 Tool/ForumPost/Video。

## Key Points
- 「禁止重复造轮子」铁律：新增互动功能必须复用 `Unified*Service` + 扩展 `TargetType` 枚举，禁止新建 `xxx_like`/`xxx_favorite` 表。
- 关键决策：砍掉评论点赞；匿名用 ipHash；主表冗余计数字段由 Service 同步；旧表 RENAME 为 `*_deprecated` 不 DROP。
- 事件源单一注入点（`addComment`/`toggleLike`）驱动 [消息通知](../entities/消息通知.md)。
- MCP 工具不绕经 InteractionController，无需改动。

## Related

- 依赖 [软删除状态机](软删除状态机.md)、[用户实体](../entities/用户实体.md)、[用户角色审批](用户角色审批.md)。
