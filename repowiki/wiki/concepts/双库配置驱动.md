# 双库配置驱动

## Definition
通过 Spring Profile 选择 MySQL 或 PostgreSQL 的配置驱动模式，使同一份业务代码与实体在两库间零改动切换。Schema 由 `ddl-auto:update` 自动生成且两库均有效。

## Key Points
- `mysql-connector-j` 与 `postgresql` 同时入 `build.gradle`；`application.yml` 多文档按 `on-profile` 切库。
- 方言自动探测（移除硬编码 MySQLDialect），Hibernate 6 按 JDBC 元数据解析；IDENTITY 主键、STRING 枚举天然可移植。
- 保留字 `user` 处理：`@Table(name="user")` + `globally_quoted_identifiers=true`，两库均视为分隔标识符。
- 同一时刻只连一库，不引多数据源路由/双写；初始化脚本按库分别提供（Makefile db / db-pg）。
