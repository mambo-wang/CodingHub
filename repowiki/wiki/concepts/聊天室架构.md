# 聊天室架构

## Definition
全局公共实时聊天的技术架构：WebSocket + STOMP + SimpleBroker（单实例，预留 Redis relay 扩展点），独立建模 `chat_message`，与异步 REST 互动（[统一互动](../entities/统一互动.md)）在传输/归属/生命周期上明确区分。

## Key Points
- 鉴权：握手 `?token=<jwt>` 构造 `ChatPrincipal`；无 token 为游客需填 displayName。
- 频率限制：`ChatService` 内存 2s/条，限流回送错误帧不入库；管理员软删除 + 广播 DELETE 事件。
- 在线人数：`ChatPresenceListener` 广播 `{online:N}`；进房加载最近 50 条；status 仅 ACTIVE/DELETED。
- 前端双入口单组件 `ChatRoom.vue` + 单 store `chat.ts`：全屏 `/chat` 与全站悬浮抽屉 `ChatLauncher.vue`。
- 复用统一互动的 IP 哈希 / XSS / 软删除 / JWT 做法，但不复用其表。
