# 用户角色审批

## Definition
三级单角色（USER/ADMIN/SUPER_ADMIN）+ 账号状态（ACTIVE/PENDING/REJECTED/DISABLED）的权限模型。角色与状态正交分离「是什么角色」与「能否使用」。

## Key Points
- `User.role` 枚举 + `User.status` 枚举；JWT 仅放 userId，filter 每次请求查库读 role/status → 审批/封禁即时生效。
- 注册选 USER→直接激活；ADMIN→PENDING 待超管审批；SUPER_ADMIN 不可注册。
- 内置超管 `admin/Cloud@1234`（`app.super-admin.password` + 环境变量覆盖），由 `DataInitializer` 创建。
- API 前缀 `/api/v1/admin/**`（pending-users/approve/reject/users/status）。

## Related
- 是 [内容审核](../entities/内容审核.md)（isOwner||isAdmin）的前置；影响 [用户实体](../entities/用户实体.md) 字段设计。
- 审批事件驱动 [消息通知](../entities/消息通知.md) 的 ADMIN_APPROVED/REJECTED。
